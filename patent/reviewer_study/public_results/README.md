# Matched-review public results

This directory contains de-identified aggregate outputs from the matched blinded B1/B2/B3 review. The study used 14 common inputs and five reviewers. Reviewers 3--5 form the prespecified primary analysis because Reviewers 1--2 had earlier exposure to B3-only material.

Included files report method summaries, paired contrasts, dimension-level summaries, inter-rater diagnostics, resource accounting, and the LaTeX tables used by the manuscript.

The release does not include completed workbooks, narrative comments, private allocation keys, input packets, artifact text, or reviewer-level rating rows. Those records are retained under access control. As a result, reviewers can inspect the reported aggregate outputs but cannot rerun the unblinding from raw human-review records.

`RESULTS.md` gives the concise interpretation and claim boundaries. In particular, the artifact-only B3--B2 composite contrast is not statistically detectable, while B3 has lower reviewer-recorded assessment time and fewer major-revision decisions under the reported conditions. Governance and mutation safety are evaluated separately.
